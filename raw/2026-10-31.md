## 三、Claude（含 Claude Code）

### 1. Claude Code v2.1.316（85/100）

**官方发布时间：** 2026-10-31 01:01 UTC（GitHub 发布记录 `published_at`）

**北京时间：** 2026-10-31 09:01 · 已确认在窗口内

**是否调整用法：需要（在用 Opus 4.8 fast mode、Team/Enterprise 服务端托管设置的场景）**

**变化内容：**

1. Opus 4.8 的 fast mode 自 2026 年 10 月 30 日起弃用，2026 年 11 月 30 日移除。移除后，Opus 4.8 的 fast mode 请求直接报错，不会回退到标准 Opus 4.8；要保留加速需迁移到 Opus 5.5。
2. 新增环境变量：`CLAUDE_CODE_DISABLE_ULTRATHINK` 关闭 `ultrathink` 关键词；`CLAUDE_CODE_SUBAGENT_EFFORT` 设定子代理在没有其他指定时使用的 effort，而不是继承会话的；`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` 保留互相认证成环的系统交叉证书，供需要它的私有 CA 使用。
3. Claude apps gateway：新增组共享的月度预算（在每个成员自己的额度之上，通过支出限额管理 API 的 `pooled_budget` 设置）；新增 `managed.policy_mode: layered`，匹配到开发者的所有策略逐层合并生效，而不只取第一条；Bedrock 上游新增 `guardrail.input_tagging`，给提示词加上 Bedrock guardrail 提示攻击过滤器需要的输入标签。
4. 变更：Team 和 Enterprise 登录时，从 Anthropic API 获取的服务端托管设置不再弹出审批提示直接生效，校验不通过的本地副本会被拒绝；`autoMode.allow` 列表不含 `"$defaults"` 时，不再移除定时任务提示上的内置规则。
5. 修复：Claude Code 自行退出时（例如凭据被拒、云端会话被归档）macOS 和 Linux 上残留运行的 shell 命令；`SHELLOPTS` 被导出时 Bash 工具启动的脚本只执行第一条命令；Vertex AI 和 Amazon Bedrock 上 `sonnet`、`opus`、`haiku` 在最新模型不可用时会话中途报错，改为切到旧模型；gateway 未对请求中的每个模型检查 `availableModels`、`deniedModels`、`models`，现在被拦截的请求返回 400 并指出字段；`--restricted` 会话在 Read 允许规则覆盖时会上传工作目录以外的文件；含不可见字符的提示需要按两次回车才发送；`/model <id>` 遇到当前版本不认识的模型时不提示自动压缩将按 20 万上下文估算；Windows 上 Grep 和 Glob 在超时后进程不退出时永不返回；以及 PowerShell hook、压缩响应中断导致请求挂起、子代理模型被切回主模型等多项问题。
6. 改进：Claude Desktop 的 Code 标签页或网页上发起的 `/code-review` 在云端和 `claude remote-control` 会话中显示结果卡片；大仓库中 `/diff` 每次刷新通常少跑一次全仓库 git 命令；SSL 证书错误会列出可能原因和对应解决办法。
7. VS Code 扩展（可在聊天面板直接登录 gateway；`ultrathink` 以 `xhigh` effort 运行）、云端会话、自托管 runner、Claude Tag、Code Review 也有多项修复和改进。

**推荐理由：**

用 Opus 4.8 fast mode 的要在 11 月 30 日前切到 Opus 5.5，否则请求会直接报错。Team/Enterprise 的托管设置现在不再弹审批提示，管理员需要知道这个变化。

**官方原文：** [Claude Code v2.1.316 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)

**是否调整用法：可以关注**

**变化内容：**
