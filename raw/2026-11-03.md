## 三、Claude（含 Claude Code）

### 1. Claude Code v2.1.317（85/100）

**官方发布时间：** 2026-11-03 01:25 UTC（GitHub 发布记录 `published_at`）

**北京时间：** 2026-11-03 09:25 · 已确认在窗口内

**是否调整用法：需要（子代理 effort、Read 工具重复读取、`claude -p` 退出码这几处默认行为有变化）**

**变化内容：**

1. 行为变化：与主对话模型不同的子代理和队友，改用该模型保存的 effort 或其默认值，不再沿用会话的 effort；Read 工具去掉“文件自上次读取后未变化”的占位返回，再次读取未改动的文件会返回完整内容；SendMessage 发给正在运行的后台代理时，其正在运行的命令转到后台而不被停止，消息更早送达；退出时插件监视器不再触发“后台任务仍在运行”提示。
2. 新增：Web 或 shell 工具调用要把你的账号邮箱发到网络前，会先询问；`/schedule` 新建的云端定时任务被加上你没要求的连接器时给出警告和移除方法；Agent SDK hook 回调新增 `onFailure: "block"`，回调失败时阻止该操作；OTel 指标、事件和 span 新增 `anthropic.plan`、`anthropic.seat_type`、`anthropic.provider`、`anthropic.custom_base_url`。
3. Claude apps gateway：管理 API 新增成本报表 `GET /v1/organizations/analytics/cost`，可按总计、开发者、天或 IdP 组读取某段时间的支出；设置了 `admin:` 的 gateway 每天记录开发者所属 IdP 组，保留 `admin.identity_retention_days`。
4. 新增环境变量 `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`：在自托管 runner 上设为 `1`，会话内运行的 `claude -p` 沿用该会话的 ID 和记录，与旧版本一致。
5. 修复：部分 Claude 桌面会话中项目和本地 MCP 服务器在第一轮后断开；作为 base URL 的 LLM gateway 对安全检查返回 403 或 422 时 auto mode 每轮失败；`claude auth status` 在慢速 token 刷新保存前退出导致下次被登出；磁盘或配额写满时 `claude -p` 仍以 0 退出（现在报错并在 text 和 json 输出下以 1 退出）；超大 CLAUDE.md 改动后自动压缩出现“Prompt is too long”；Grep 和 Glob 超时后把部分结果当作完整结果；某些 TLS 检查代理在根证书续期后报“unable to get local issuer certificate”；Ctrl+C 清空输入时停止所有后台代理；以及 `/loop`、`/schedule`、`/team-onboarding`、agent team、OpenTelemetry 导出等多项问题。
6. 改进：Microsoft Foundry 上 Azure 凭据加载失败、gateway 无法连接时的错误提示更明确；退出时“Resume this session with”提示会带上启动时的参数；自托管 runner 遇到 5xx 或心跳无响应后改为新建连接。
7. Windows、VS Code 扩展、云端会话、Remote Control、自托管 runner、Claude Tag 也有多项修复和改进。

**推荐理由：**

子代理 effort 的取值来源变了，Read 工具重复读取会返回完整内容（可能多占上下文），脚本里依赖 `claude -p` 退出码的要知道写盘失败现在返回 1。

**官方原文：** [Claude Code v2.1.317 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)
