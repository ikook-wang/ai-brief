## 三、Claude（含 Claude Code）

### 1. Claude Code v2.1.295：安全机制与自动化稳定性更新（88/100）

**官方发布日期：** 2026-10-08 19:48 UTC

**北京时间：** 2026-10-09 03:48 · 已确认在窗口内

**是否调整用法：需要（使用 Hooks、MCP 或自动化任务的场景）**

**变化内容：**

Claude Code 发布 v2.1.295，主要更新包括：

1. **新增安全失败阻断机制。** 新增 `onFailure: "block"`，允许命令及 HTTP Hooks 在启动失败、超时或异常退出时阻断原本要执行的操作，而不是默认放行。
2. **修复远程 MCP 重连问题。** 修复了 Headless 和 SDK 会话中，远程 MCP 服务器发生较长时间故障后无法正常重连，以及反复连接失败时频繁重试的问题。
3. **修复自动化任务输出丢失。** 修复 `claude -p` 在后台任务触发新一轮执行时，可能丢失前序文本输出的问题。
4. **增强终端状态显示。** 新增 Program Status Protocol（OSC 7501）支持，使兼容的终端可以显示 Claude Code 正在工作、等待用户操作还是已经完成。
5. **修复权限与后台任务问题。** 包括部分工具权限限制未正确生效、后台任务执行顺序异常等问题。

**推荐理由：**

这次更新对自动化开发场景比普通交互场景更有价值。

如果你使用 Claude Code 自动执行脚本、操作仓库、调用远程 MCP 服务，或者通过 CI/CD、SDK 执行无人值守任务，建议升级并重点测试安全 Hooks 和重连机制。

其中 `onFailure: "block"` 值得关注，因为它能减少安全检查失败后操作继续执行的风险。

如果只是进行普通交互式开发，不需要修改现有流程。

**官方原文：** [Claude Code v2.1.295 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.295) [GitHub](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)

### 2. Anthropic 更新 2026 年使用政策（82/100）

**官方发布日期：** 2026-10-08 17:00 UTC

**北京时间：** 2026-10-09 01:00 · 已确认在窗口内

**是否调整用法：可以关注**

**变化内容：**

Anthropic 发布新版 Usage Policy（使用政策），主要针对 Claude 模型能力提升后的新使用场景，进一步明确使用边界。

主要变化包括：

1. **加强对欺骗性行为的限制。** 新增针对欺骗性活动和人为制造虚假互动的独立章节，明确禁止利用 Claude 批量制造虚假内容、操纵舆论或建立虚假账号网络。
2. **调整政治和选举相关限制。** 更明确地聚焦于欺骗选民、干扰选举等行为，同时移除对个性化选民沟通和竞选定向的一刀切禁令，但欺骗行为和滥用个人信息仍被禁止。
3. **明确武器开发与监控限制。** 进一步说明武器控制软件、监控系统、未经同意的人员追踪等行为的限制范围。
4. **明确高风险 AI 应用要求。** 对医疗、金融、法律权益等可能影响个人重大利益的场景，强调必须有具备相应资格的人员进行审核，并告知相关人员 AI 的参与情况。对于能够自主执行物理动作的硬件，增加了人工监控和安全停止方面的要求。
5. **新增针对模型的持续恶意行为限制。** 禁止持续且无正当目的地对模型实施极端辱骂或残酷行为，但普通用户的不满、批评、测试和研究不受此限制。
6. **进一步明确地区使用限制。** 说明不支持地区的个人、注册或总部位于不支持地区的实体，以及由这些地区的个人或实体多数持有或控制的组织，均受到相关访问限制。

**政策生效日期：2026 年 11 月 12 日。**

Anthropic 表示，本次多数调整是对现有规则的澄清，而不是全面新增限制。[Anthropic](https://www.anthropic.com/news/2026-usage-policy-update)

**推荐理由：**

这不是模型能力升级，也不会直接改变 Claude 的日常编程体验。

但如果使用 Claude 开发商业产品、构建 AI Agent，或者让模型自动执行具有现实影响的任务，就值得关注。

尤其需要留意：

- **AI Agent：** 自动执行敏感操作时，应设置权限边界和人工审核机制。
- **商业产品：** 如果将 Claude 集成到金融、医疗等高风险业务，需要确认是否符合相关使用要求。
- **地区限制：** 如果通过企业账户或第三方服务使用 Claude，需要确认实际使用方式符合 Anthropic 的支持地区政策。

对于日常代码编写、问题分析和普通开发工作，目前不需要因此改变工具使用习惯。

**官方原文：** [Anthropic — 2026 Usage Policy Update](https://www.anthropic.com/news/2026-usage-policy-update)
