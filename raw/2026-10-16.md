## 一、Codex

### 1. Codex CLI 0.163.0（80/100）

**官方发布时间：** 2026-10-15 21:30 UTC（GitHub 发布记录 `published_at`）

**北京时间：** 2026-10-16 05:30 · 已确认在窗口内

**是否调整用法：可以关注**

**变化内容：**

1. 新增可搜索的 `/config` 偏好面板，支持的设置立即生效，并提示哪些改动需要重启。
2. Codex 回复过程中可以直接发送追加消息来引导它；中断一轮对话时会同时停止正在运行的 Code Mode 单元及其嵌套工具调用。
3. 可以在 `/keymap` 里配置 leader 键，默认 `Ctrl+X`；语音静音改到 `F9`。
4. 可以在 `/daemon` 中重启托管的后台服务，Codex 会先提示可能被中断的工作，然后自动重连。
5. 相互独立的只读工具（包括 skill、memory、会话历史查询）可以并行执行。
6. Daybreak 对符合条件的账户默认开启；`codex exec` 在服务端提供访问时也可以用 OpenAI API key 选择它。
7. 修复：恢复已保存的会话时会恢复其权限和网络审批；网络代理在 DNS 查询前先检查权限、拒绝重复的 `Host` 头；Windows 下 `Ctrl+V`、`Shift+Insert` 可以粘贴文本；`codex exec` 不再重复打印同一个文件 diff 等。
8. 不再捆绑打过补丁的 `zsh`，使用已退役 shell 配置项的会收到迁移提示。

**推荐理由：**

用 Codex CLI 的值得升级。`/config` 面板、回复中途追加引导和只读工具并行，对日常使用体验改善明显；用了旧 shell 配置项的，要留意迁移提示。

**官方原文：** [Codex rust-v0.163.0 Release](https://github.com/openai/codex/releases/tag/rust-v0.163.0)

另：窗口内还有两个预发布版本 rust-v0.163.0-alpha.10.2（UTC 10-15 18:26，北京 10-16 02:26）和 rust-v0.164.0-alpha.1（UTC 10-16 14:49，北京 10-16 22:49），发布记录正文只有版本号，没有更新内容，不单独列出。

## 三、Claude（含 Claude Code）

### 1. Claude Code v2.1.301（85/100）

**官方发布时间：** 2026-10-15 19:22 UTC（GitHub 发布记录 `published_at`）

**北京时间：** 2026-10-16 03:22 · 已确认在窗口内

**是否调整用法：需要（无人值守、OpenTelemetry、切换模型的场景）**

**变化内容：**

1. 新增 `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`：无人值守重试模式遇到重置时间太远的用量上限时，直接结束请求而不是一直等。
2. OpenTelemetry `tool_decision` 事件新增 `classifier_verdict`、`permission_mode`、`classifier_category`，可以区分 auto mode 分类器的决定和权限规则。
3. vim 模式新增 `%` 跳转匹配括号。
4. 修复：退出时不再未经询问就删除 `WorktreeCreate` hook 创建、可能含未推送提交的 worktree；`fable`（和 `best`）别名在组织拿不到最新 Fable 模型时会回退到上一个 Fable 模型；切换到上下文更小的模型时不会未经询问就花额度做摘要；Grep、Glob 搜索程序异常时报错而不是显示无结果；Read 工具不再把 .xlsm、.parquet 等二进制文件当文本读。
5. 改进：切换到上下文更小的模型时，过长的对话会先由原模型摘要。
6. VS Code 扩展：支持 LaTeX 数学公式渲染等。

**推荐理由：**

用 worktree hook、无人值守重试或 OpenTelemetry 审计的，这版修复和新增字段直接相关，值得升级；普通交互使用照常升级即可。

**官方原文：** [Claude Code v2.1.301 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)
